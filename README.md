# Поиск выхода из лабиринта

Учебный проект на Python для поиска пути в лабиринте.

## Описание

Программа считывает лабиринт из файла `labyrinth.txt` и находит путь от входа **A** к выходу **B** с помощью волнового алгоритма.

## Обозначения

* `1` — стена
* `0` — свободная клетка
* `A` — вход
* `B` — выход

## Результат

Программа выводит:

* карту лабиринта с рассчитанными расстояниями
* последовательность шагов до выхода.

## Цель проекта

Практика работы с файлами, двумерными массивами и алгоритмами поиска пути.
